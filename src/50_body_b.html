技能库

九个跑通的技能，从建模到出图。

每个技能都是一段可复用的 Agent 工作流。交付前必须回读自检：面数、实体数、外观和渲染图都对得上，才算完成。

SolidWorks 建模

用 COM API 自动建草图与特征：拉伸、切除、拔模、圆周阵列、焊件、钣金。逐件渲染自检后交付带外观的 SLDPRT。

看建模流程

SolidWorks 装配

AddComponent + AddMate3 公式化装配。轻化是万恶之源：插完件要趁还原态立刻取配合面。11 件一次装成。

看装配脚本

Motion 运动算例

用 Motion API 建算例、加旋转马达、计算并采样角速度，把运动量在出图之前先量出来，不留到最后才发现。

看运动仿真

EPLAN 电气原理图

通过本地 MCP 驱动 Electric P8：新建页、放符号、画连线与换相交叉、打设备代号，导出 PDF 与 DXF。

看原理图

CAXA 电子图板

2026 版没有可用的 COM 接口，改用 DXF 生成加按键模拟这条通道，已完成出图验证。

看替代通道

渲染与出图

材质写进本体、清掉实体级覆盖，再渲染并截屏验证。避免出现「PNG 是彩的、屏幕是灰的」这种假阳性。

看交付准则

Photoshop 自动化

python + JSX 驱动 CC2019，输出名片、海报这类版式成品，出血与单色黑一次到位。

看版式脚本
